Radio button

차량 내 조작이 필요한 스위치 중 하나로 독립적인 선택 옵션을 제공할 때 사용됩니다.​

1. Root : Checkbox 컴포넌트를 감싸는 최소단위 컨테이너 영역
2. Control : 체크박스의 상태를 나타내는 시각 요소

States​

StateValueDescription
Value (Selected)Num / NullNull: 선택되지 않은 Radio
Num: 선택된 Radio의 순서 값
PressedBoolean터치로 클릭 중인 상태일 때 True로 전환
DisabledBooleanTrue일 경우, Radio 제어 불가능한 상태
InvalidBooleanTrue일 경우, 유효하지 않은 값임을 나타냄
