Text button

텍스트 버튼은 부가 정보에 대한 링크를 위해 주로 사용되며, 앞/뒤 아이콘을 통해 정보 전달력을 강화할 수 있습니다.​


1. Root : 버튼을 감싸는 최상위 컨테이너 영역
2. Label : 버튼 레이블
3. Icon(Prefix) : Label에 대한 시각적 부연설명을 하는 아이콘 영역
4. Icon(Suffix) : Label에 대한 시각적 부연설명을 하는 아이콘 영역

States​

StateValueDescription
PressedBoolean터치로 클릭 중인 상태일 때 True로 전환
DisabledBooleanTrue일 경우, Button이 제어불가능한 상태
LoadingBooleanTrue일 경우, Button내 Loader가 표시되고 제어불가한 상태가 됨


Properties​

StateValueDescription
SizeMedium, SmallButton의 사이즈 옵션을 선택하여 사용할 수 있습니다.
