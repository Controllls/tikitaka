These fixtures belong only to the instrumentation-test APK. They are NOT included
in the application APK. The app does not contain or automatically import sample audio.

laugh-negative-*.m4a
Five negative controls from ESC-50, converted to mono 44100 Hz AAC (96 kb/s).
Exact original filenames, Freesound source IDs, and categories are listed in
laughter-control-attribution.json. Dataset: https://github.com/karoldvl/ESC-50
Dataset distribution: CC BY-NC 3.0, https://creativecommons.org/licenses/by-nc/3.0/
Used only for noncommercial instrumentation testing; excluded from production APK.

tiki-synthetic-3.m4a: AAC conversion of sample-3.wav (FFmpeg, 96 kb/s).
Used for the deterministic queued-production integration test. No user recording.

momo-synthetic-korean.m4a
Synthetic Korean speech generated for backend/video integration testing.
Contains no user recording.

auto-highlight-synthetic.m4a
Concatenates momo-synthetic-korean.m4a and 1-73123-A-26.m4a, re-encoded as
mono 44100 Hz AAC (96 kb/s). The laughter source and dataset terms below apply.
Used only for noncommercial automatic-highlight integration testing.

silence_8000.m4a
Generated digital silence: FFmpeg anullsrc, mono 44100 Hz, 8 seconds, AAC.

1-73123-A-26.m4a
Derived from ESC-50 audio/1-73123-A-26.wav, converted to mono 44100 Hz AAC (96 kb/s).
Original: 0524laugh.wav by sagetyrtle, CC0.
https://freesound.org/people/sagetyrtle/sounds/73123/
https://creativecommons.org/publicdomain/zero/1.0/

laughing.m4a
Derived from ESC-50 audio/1-30043-A-26.wav, converted to mono 44100 Hz AAC (96 kb/s).
Original: small group laugh 6.flac by Corsica_S, CC-BY (per ESC-50 attribution).
https://freesound.org/people/Corsica_S/sounds/30043/

Dataset: ESC-50, Karol J. Piczak.
https://github.com/karoldvl/ESC-50
https://github.com/karoldvl/ESC-50/blob/master/LICENSE
Dataset distribution terms: Creative Commons Attribution Non-Commercial 3.0.
https://creativecommons.org/licenses/by-nc/3.0/
These excerpts are included for noncommercial regression testing only.
The weak group-laugh sample is also evaluated to expose missed detections; it is
not an accuracy benchmark, and tests do not assert perfect recall.

pleos-playback.mp4: Three-second regression fixture generated by this project's
MomoVideoTest.suppliedResourcesEncodeThreeAndThirtySeconds using sample-3.wav,
result-3.json, tracks-3.json and the existing MOMO preset resources. No user
recording is included. Used only to verify video playback restriction paths;
androidTest assets are not packaged in the product APK.
