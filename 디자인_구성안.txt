2. 앱에 적용한 구조

상단: 이동 기록 브랜드 / DRIVE JOURNAL / 기기 내 보관
소개: 오늘의 대화, 하나의 기록.

넓은 창:
  왼쪽 큰 카드                     오른쪽 보조 카드
  - 현재 녹음 상태                  - 탑승 상태
  - 녹음 안내 제목                  - 실제 저장 개수와 총 시간
  - 큰 주황색 마이크/정지 버튼        - 가장 최근의 실제 녹음
  - 원형 파동과 입력 크기 표시        - 음성 보관 안내
  - 경과 시간과 저장 결과

하단: 홈 / 저장된 기록

창 너비 900dp 미만에서는 카드가 세로로 이어집니다.
화면 높이가 부족하면 내용을 스크롤하고 하단 메뉴는 계속 표시합니다.
좌측 차량 화면, 상단 차량 상태, 최하단 공조 조작은 Pleos 시스템 영역입니다.
이번 디자인은 그 안의 앱 영역에 적용했습니다.

3. 디자인 기준

배경: #0B1018
카드: #141D29
주요 강조: #FFAD58
주요 글자: #F4F5F7
보조 글자: #A0ADBE

카드 모서리는 22dp, 카드 사이 간격은 20~24dp입니다.
기본 화면 여백은 20dp, 넓은 창에서는 32dp입니다.
대표 조작은 마이크 버튼 하나에 집중합니다.
녹음 중에는 정지 모양으로 바뀌고 실제 입력 크기에 맞춰 주변 선이 움직입니다.
저장 기록이 없으면 가상의 기록 대신 빈 상태 안내를 보여줍니다.
기록 수와 총 시간, 최근 항목은 앱 안에 실제로 저장된 파일에서 계산합니다.

4. 기록 목록

- 같은 남색·주황색 팔레트와 둥근 카드로 연결했습니다.
- 녹음 날짜, 시간, 파일 크기를 항목별로 표시합니다.
- 기록 선택 → 재생/일시정지/삭제 흐름을 유지합니다.
- 기록이 없을 때는 녹음 화면으로 돌아가는 버튼을 표시합니다.
- 녹음 동의 안내는 큰 녹음 카드 안에 표시합니다. 재생 팝업은 같은 어두운 색상입니다.

6. 검증

- debug APK 빌드 및 lint 통과.
- 실제 Pleos 에뮬레이터에서 새 화면을 확인하고 설치했습니다.
- 하단 메뉴와 최근 기록 카드로 목록 이동 확인.
- 동의 이전 녹음 없음, 녹음/종료, 저장 후 통계 갱신 확인.
- 저장 항목 재생 및 삭제 후 통계 갱신 확인.
- 검증 후 녹음 서비스를 종료하고 대기 화면으로 복귀했습니다.

7. 팝업을 없앤 탑승 안내

탑승 신호가 들어오면 큰 녹음 카드에
'탑승을 확인했어요. 이번 이동을 기록할까요?'를 표시합니다.
테두리를 두 번 은은하게 강조하고 마이크 주변을 밝게 표시합니다.
버튼 아래에는 '눌러서 녹음 시작'과 '이번에는 안 함'을 표시합니다.
동승자의 동의를 확인하라는 설명은 같은 카드 아래에 계속 표시합니다.
시간 표시와 실제 소리에 반응하는 움직임은 녹음을 시작한 뒤 보여줍니다.
건너뛴 탑승에는 안내를 반복하지 않으며, 빈 좌석 후 다시 탑승하면 안내합니다.
시스템 마이크/알림 권한은 필요한 경우 별도로 요청합니다.

8. 화면 밖 탑승 안내 설정

오른쪽 '이번 이동' 카드에 '앱을 닫아도 탑승 안내' 스위치를 배치했습니다.
꺼짐 / 대기 시작 / 차량 연결 중 / 안내 대기 / 녹음 중 / 연결 실패 상태를 설명합니다.
알림이 차단되어 있으면 '알림 설정' 버튼을 표시합니다.
화면 밖에서는 시스템 알림으로 안내하고, 선택하면 기존 큰 녹음 카드로 돌아옵니다.
알림 선택만으로 녹음이 시작되지 않습니다.
