이 인증서는 자체 서명이며 실명 인증·공모전 승인·SDK 이용 승인을 의미하지 않는다.
서명 검증용 인증서는 APK에 포함된다. 비밀키와 비밀번호를 심사자에게 전달하지 않는다.
비밀키는 Git 저장소 밖 사용자 비공개 디렉터리에 보관했다.
비밀번호는 Windows DPAPI로 암호화했고 디렉터리 ACL을 현재 사용자와 SYSTEM으로 제한했다.
암호화 파일은 같은 Windows 사용자·컴퓨터에서만 복호화할 수 있다.
Windows 재설치 또는 다른 PC 이전 전에 별도 비밀번호 관리자와 안전한 키 백업이 필요하다.

다음 APK 서명:
.\tools\sign-contest-apk.ps1

도구는 키·비밀번호가 있으면 덮어쓰지 않고 중단한다.

서명 성공, APK 설치 성공, 앱 실행 성공, 기능 검증은 각각 별도 항목이다.
