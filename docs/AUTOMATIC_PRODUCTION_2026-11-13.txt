티키타카 웃음 기준 하향 및 새 버전 자동 제작
2026-11-13

변경한 기능과 화면
- 웃음 감지의 앱 기본값/최소값을 0.01에서 0.001로 낮췄다. 0.005 중간 선택지도 추가했다.
- 설치된 에뮬레이터 앱에도 0.001을 저장하고 읽어 확인했다. 임계값이 작을수록 약한 점수도 후보가 되며 정확도가 10배 좋아진다는 의미는 아니다.
- 설정 UI, 저장값 복원, YAMNet 판정의 입력 검증, 기기 하이라이트 계획의 입력 검증을 함께 변경했다.
- 새 버전 제작 시 인원/다시 분석/내 목소리 사용 여부를 확인하던 창을 제거했다. 버튼을 누르면 현재 웃음 기준으로 다시 분석하고 현재 목소리 등록 정보를 사용해 별도 영상을 만든다.
- 길이와 웃음 기준은 설정 화면에서 변경할 수 있다. 제작 시마다 다시 선택할 필요가 없다.
- 녹음 파일의 영상 만들기, 기존 영상의 새 버전 만들기, 후보 없는 작업의 재분석에서 같은 자동 제작 경로를 사용한다.
- 연속 클릭/이미 진행 중인 작업은 중복 생성하지 않는다. 녹음 중/주행 제한 상태의 기존 실행 제한은 유지한다.

인원 결정
- 각 영상으로 선택된 음성 구간에서 기기의 화자 모델로 확인한 화자 수에 맞춰 1~4명을 배치한다. 예전의 수동 4명 설정이 있어도 1명만 감지하면 새 버전은 1명으로 만든다.
- 이는 좌석 센서로 확인한 실제 탑승 인원 수가 아니다. 말하지 않은 사람은 음성만으로 셀 수 없다.
- 화자 수를 확인하지 못한 구간은 임시 캐릭터 2명으로 연출하며 '화자 미확정'과 unknown-voice-fallback으로 표시한다. 2명을 실제 검출했다고 기록하지 않는다.
- 기존 완료 영상은 유지한다. 새 버전은 분석 시도 번호와 출력 버전을 증가시켜 예전 감도/인원 설정의 결과와 구분한다.

검증
- Debug 앱/계측 APK 빌드 및 JVM 테스트 61개 통과. Lint 오류 0건, 경고 87건.

- 실제 새 버전 버튼을 연속 클릭한 계측 검사에서 확인창 없이 작업을 한 번만 생성했다. 분석 시도 +1, 영상 버전 +1, 감도 0.001, 영상 완료와 이전 MP4/원음 해시 보존을 확인했다.
- 해당 웃음 샘플에서는 화자 수 0으로 판단해 임시 2명을 사용했고, 결과에 미확정으로 기록됨을 확인했다.
- 실제 단일 음성 및 기존 공개 참조 음성의 2명/4명 구분 검사와 자동 배치 검사 통과. 이들 3개 계측 테스트 실행 시간은 합계 96.128초이며 실사용 대화의 제작 시간으로 해석하지 않는다.
- 작업 전 원음·영상·분석·하이라이트 파일 243개가 모두 같은 SHA-256으로 보존됐다.
- 산출물: build/reports/laughter-threshold/의 benchmark-0.001.json, current-setting.json, automatic-recreation.json, diarization-*.json, preservation.json.
