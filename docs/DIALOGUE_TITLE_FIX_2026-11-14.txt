대화 분석 제목 적용 수정 및 실제 앱 확인 — 2026-11-14

기획 기준
- IDEA DECK 22페이지의 '대화에 근거한 제목과 장면 구성'을 기준으로 점검했다.
- 이 기능은 프로젝트 구현 요구이며 Pleos 공식 플랫폼 요구나 공식 수치가 아니다.
- 대상은 한국어 차량 엔터테인먼트 앱, 현재 Pleos Connect v2.1.0 에뮬레이터다.

확인한 원인
- 당시 보관함의 영상 17개에는 새로운 story 생성 결과가 없었다. 최근 영상도 wide7 방식이었다.
- 실제 사용자 앱의 no_backup/story-models 폴더가 없어 제목 모델이 준비되지 않은 상태였다.
- 이전 구현은 모델 실행/출력 검증에 실패하면 첫 자막 기반 기본 제목으로 제작을 완료했다.
- STT가 긴 대화를 한 구간으로 반환하면 모델 입력에서 첫 200자만 남아 뒷내용이 빠졌다.
- 실제 테스트 전사문에는 '술 가족'처럼 부정확한 표현도 포함돼 있었다.

변경한 기능
- 대화가 긴 단일 자막이어도 분할하고 시작·중간·끝을 포함한다. 입력은 최대 6그룹, 960자다.
- 한국어 시트콤 제목 지침으로 핵심 행동/상황을 중심으로 생성한다. 원문의 첫 부분을 복사한 제목은 검증에서 거부한다.
- 잘못된 형식의 제목은 한 번 더 생성한다. 그래도 실패하면 원음/분석을 남기고 제작 실패 원인을 표시한다.
- 모델 오류를 첫 자막 제목으로 대체하여 완료하는 경로를 제거했다. 전사문 자체가 없는 경우의 기본 연출은 별도다.
- 생성 규칙 버전을 dialogue-story-v3로 올려 이전 규칙의 결과를 그대로 재사용하지 않는다.
- 최초 모델 다운로드의 전체 요청 5분 제한을 제거했다. 기존 읽기 제한 30초, 작업 8분 단위의 취소/이어받기와 SHA-256 검증은 유지한다.
- 기존 완성 영상은 그대로 두고, 기존 원본의 분석 체크포인트로 새 버전을 만들었다.
