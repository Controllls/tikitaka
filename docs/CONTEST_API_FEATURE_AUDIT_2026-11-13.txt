티키타카 전체 기능의 공모전 SDK·API 적합성 검토
검토일: 2026-11-13 / 기준 커밋: 552e116f8b0317c8cb75b81c266601de7dd37382
범위: 현재 Android 앱의 사용자 기능, 백그라운드 작업, 연결 서버 및 남아 있는 웹 실험 경로
방법: 코드·병합 매니페스트 검토, 현재 공식 웹 문서 확인, 사용자 제공 설명회 자막, 기존 실측 기록 대조
이번 작업은 검토이며 제품 동작을 수정하지 않았다. Figma 전체 디자인 적합성 재심사는 아니다.

결론
외부 API·자체 서버·Android 기본 API를 사용한다는 사실만으로 위반이라고 볼 수 없다.
그러나 설명회 발언만으로 현재 앱의 모든 기능이 허용되고 정상 동작한다고 확정할 수는 없다.
핵심 미확정 사항은 차량 원음의 별도 녹음·보관이다. 구체적인 구현 문제는 STT 완료 오류, 동의 범위 재사용, 삭제·철회 기능 부족이다.
휴대폰에 공유하는 완성 영상에는 실제 음성이 들어 있다. '원본 M4A 미전송'을 '음성 데이터가 절대 기기 밖으로 나가지 않음'으로 설명하면 안 된다.

3. 우선 수정 또는 확인해야 할 구체적 사항

I-01 [지원 범위 미확정] 차량 원음 별도 녹음·보관
외부 API 일반 허용만으로 확정할 수 없는 핵심 전제. MediaRecorder/AudioRecord를 이용한 로컬 취득·보관과 완성 영상의 선택적 전송을 기능 단위로 구분해 판단해야 한다.
에뮬레이터 재생 성공과 공모전 허용 여부는 서로 다른 결론이다.

I-02 [실제 기능 결함] STT 완료 타임아웃
28.096초 실제 마이크 입력 녹음에서 전사 결과를 받고도 39.039초 후 TIMEOUT.
입력 도중 발생한 종료 콜백 6개를 전체 완료 대기에서 무시하고, completeAudioSend() 뒤 오지 않는 종료 콜백을 기다린다.
공식 SDK 선택과 별개로 자막 품질·처리 지연에 영향을 주는 수정 대상이다. [V1]

I-03 [동의 흐름 결함] 녹음만 보관 동의를 서버 전송 동의로 재사용
코드상 재현 경로:
  1) '이번에는 녹음만 보관' 선택 → 기기에만 보관한다는 동의문 확인.
  2) consentVersion=tikitaka-local-v2 저장.
  3) 다음 녹음에서 해당 체크를 해제해 영상 제작 선택.
  4) 같은 consentVersion을 확인하여 전사문 전송 동의 팝업을 건너뜀.
  5) 정상 녹음 종료 시 metadata 제작·전송 작업 예약.
근거: TikiRecordingConsent.kt:84 / TikiActivity.kt:397,404,415 / RecordingService.kt:270
이번에는 실제 녹음/전송을 발생시키지 않고 분기와 문구를 대조했다. 두 목적의 동의를 별도로 기록하거나 목적 변경 시 재동의해야 한다.

I-04 [데이터 관리 기능 부족] 삭제·철회와 실제 보관 범위의 차이
메인 앱에 삭제 UI 없음. '다시 확인'은 저장 목소리 삭제가 아님. 작업별 특징 사본·분석 캐시는 자동 삭제되지 않음.
휴대폰 연결 해제도 서버 파일을 지우지 않는다. 현재 고지에는 보관 설명이 있으나 사용자가 제공 철회/전체 삭제를 완료하는 기능은 부족하다.
S8의 입점 규칙을 공모전 자동 탈락 사유로 확정하지 않는다.

I-05 [지원 범위·완성도 표시] 시동 종료와 Gleo 실행 보조
시동 종료는 Debug의 가상 콘솔 조회뿐이고 Release는 미구현. 'Gleo 부르기'는 공개 App Schema API와 구분되는 특정 패키지 호환 동작이다.
심사 자료에는 확인한 에뮬레이터/SDK 버전과 구현 범위를 적어야 한다.

I-06 [주행 대응 보완] 입력·설정의 상태 전환
영상은 실제 시작 경로까지 차단하지만 모든 입력/설정에 동일한 보장이 있는 것은 아니다.
입력창/열린 설정 창의 제한 상태 전환, 주행 중 녹음 종료 접근성, DO 미선언 플랫폼 동작을 함께 검증해야 한다.

I-07 [제출 설명 오류] README와 현재 코드가 섞여 있음
README.md:57의 과거 서버 원음 업로드 흐름, :89의 서버 분석 설명, :242의 STT SDK 미사용 설명은 현재 제작 경로와 맞지 않는다.
