## 언어 모델 제거 검증

제목은 대사에서 반복 단어와 문장 길이를 기준으로 선택하며 24자 이내로 제한합니다. 확인된 대사가 없으면 기본 제목으로 진행합니다. 모델 다운로드·추론 JNI·C++ 빌드 스크립트와 두 ABI의 제목 추론 라이브러리를 제거했습니다. debug/release APK 안에 해당 라이브러리가 없는 것을 확인했고, 음성 분석용 ONNX Runtime·sherpa-onnx는 유지합니다.

debug·release 빌드, Android 기기 테스트 코드 컴파일, 단위 테스트 83개 및 release lint가 통과했습니다. Pleos API34 x86_64의 별도 검증 앱에서 제목 설정·MP4 렌더링과 대사 없는 경우를 확인했습니다. 일반 앱에는 업데이트를 설치하고 기존 자료 보존 및 모델 캐시 제거를 확인했습니다. 이전 영상은 다시 만들거나 제목을 일괄 변경하지 않습니다. 새 제작은 별도 파일 이름을 사용해 기존 결과를 보존합니다.

이번 변경의 적용 규칙은 STATE-01(자료·상태 유지), STATE-04(불필요한 작업 제거), DRIVE-02(주행 영상 차단 유지)입니다. SDK 의존성은 README의 빌드 환경과 동일합니다. 제목 처리 성능의 실차 수치는 측정하지 않았습니다.

## 저장소 정리

현재 UI에서 접근하지 않는 옛 홈·녹음 목록·영상 제작·인물 편집 화면과 전용 ViewModel·XML을 제거했습니다. 해당 화면만 검증하던 테스트는 함께 정리하고, 암호화 프로필 저장·영상 렌더링·현재 Tiki 화면 테스트는 유지했습니다.

기존 작업 마이그레이션, 원본 녹음 복구, Gleo Intent를 받는 `HighlightsActivity`, 현재 렌더러와 음성 분석 모델, 데이터 스키마는 유지합니다. 오래됐다는 이유만으로 데이터 호환 코드를 삭제하지 않습니다.

PC 실험 서버, 디자인 중간 추출물, 오래된 구성안·일일 보고서는 체크섬을 확인한 외부 백업으로 옮겼습니다. 사용자 녹음·영상·분석 데이터와 로컬 가상환경은 삭제하지 않았습니다.

정리 후 debug·release APK 빌드, Android 기기 테스트 코드 컴파일, 단위 테스트 72개(실패·오류·건너뜀 0개), release lint가 통과했습니다. 이번 정리 후 기기에서 전체 시나리오를 다시 실행하지는 않았습니다.

## 미검증 범위

- 실차·ARM 기기의 성능, 메모리와 실제 시동 OFF 연동.
- 모든 화면 프리셋에서의 현재 버전 재검증.
- 최종 서명 release APK의 녹음부터 영상 제작까지 전체 시나리오.
- 최신 Figma 원본과의 전체 대조. README 이미지는 11월 12일 내보내기 보존본이며 실제 앱 캡처가 아닙니다.

현재 에뮬레이터는 `IGNITION_STATE`를 제공하지 않으므로 해당 기능을 검증 완료로 표시하지 않습니다. 공개 APK 다운로드와 공모전 접수 메일 발송도 별도 작업입니다.
