# 검증 현황

기준일: 2026-11-14. 실제 차량 검증과 에뮬레이터 검증을 구분합니다.

## 기존 기능 검증

| 항목 | 확인한 결과 |
| --- | --- |
| 단위 테스트 | 제목 생성·주행 제한을 포함한 72개 통과 기록 |
| 제목·영상 | Pleos 에뮬레이터에서 모델 다운로드·SHA256 검증·제목 생성·MP4 저장·앱 표시 확인 |
| 주행 제한 | 실제 CarUxRestrictions 콜백에 따른 영상 정지·탐색 차단, 주차 후 수동 재생 확인 |
| release | 전용 키 서명·정렬·설치·프로세스 실행 확인. 전체 제작 시나리오와 구분 |
| 환경 | Pleos Connect v2.1.0, Android 14 API34, x86_64. 최근 기능 검증 앱 창 1682 × 1210 dp |

위 값은 개발 기록이며 플랫폼이 정한 최소 사양이 아닙니다. 앱 창 dp와 전체 디스플레이 px는 다른 값입니다.

## 저장소 정리

현재 UI에서 접근하지 않는 옛 홈·녹음 목록·영상 제작·인물 편집 화면과 전용 ViewModel·XML을 제거했습니다. 해당 화면만 검증하던 테스트는 함께 정리하고, 암호화 프로필 저장·영상 렌더링·현재 Tiki 화면 테스트는 유지했습니다.

기존 작업 마이그레이션, 원본 녹음 복구, Gleo Intent를 받는 `HighlightsActivity`, 현재 렌더러와 모델, 데이터 스키마는 유지합니다. 오래됐다는 이유만으로 데이터 호환 코드를 삭제하지 않습니다.

PC 실험 서버, 디자인 중간 추출물, 오래된 구성안·일일 보고서는 체크섬을 확인한 외부 백업으로 옮겼습니다. 사용자 녹음·영상·분석 데이터와 로컬 가상환경은 삭제하지 않았습니다.

정리 후 debug·release APK 빌드, Android 기기 테스트 코드 컴파일, 단위 테스트 72개(실패·오류·건너뜀 0개), release lint가 통과했습니다. 이번 정리 후 기기에서 전체 시나리오를 다시 실행하지는 않았습니다.

## 미검증 범위

- 실차·ARM 기기의 성능, 메모리와 실제 시동 OFF 연동.
- 모든 화면 프리셋에서의 현재 버전 재검증.
- 최종 서명 release APK의 녹음부터 영상 제작까지 전체 시나리오.
- 최신 Figma 원본과의 전체 대조. README 이미지는 11월 12일 내보내기 보존본이며 실제 앱 캡처가 아닙니다.

현재 에뮬레이터는 `IGNITION_STATE`를 제공하지 않으므로 해당 기능을 검증 완료로 표시하지 않습니다. 공개 APK 다운로드와 공모전 접수 메일 발송도 별도 작업입니다.
